## 搬瓦工官网打不开？分三种情况处理

打开搬瓦工官网失败，原因不同，处理方式也不一样。

**第一种：换个镜像地址**

如果 bandwagonhost.com 打不开，先换 bwh81.net 试试。大多数情况下，两个网址不会同时失效，换一个通常就解决了。

**第二种：检查搬瓦工状态页**

搬瓦工有一个公开的系统状态页 bwhstatus.com，可以用来确认是不是平台本身出了问题。如果状态页显示"All Systems Operational"，说明搬瓦工服务本身没有故障，问题出在本地网络或 DNS。

**第三种：清除 DNS 缓存或切换 DNS**

本地 DNS 缓存污染也会导致某些域名无法正常解析。把 DNS 切换为 8.8.8.8（Google）或 1.1.1.1（Cloudflare）之后刷新重试，很多时候直接就通了。
